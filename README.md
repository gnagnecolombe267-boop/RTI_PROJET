# RTI_PROJET
Recueil des besoins fonctionnels en vue de la mise en place d'une application de 
gestion des informations juridiques relatives aux partenaires de la RTI.

1-Contexte

Une séance de travail a été organisée avec le Service Juridique afin d’analyser son 
mode de fonctionnement actuel et d’identifier les besoins liés à la digitalisation du 
traitement des informations juridiques. 
Le Service Juridique exploite un journal papier contenant diverses publications 
relatives aux partenaires de la RTI. Ces publications portent notamment sur des 
événements juridiques tels que les transferts de siège, les cessions, les changements de 
dénomination sociale, les modifications de dirigeants, les procédures collectives et tout 
autre acte pouvant avoir un impact sur les relations de la RTI avec ses partenaires. 
Fonctionnement actuel 
À ce jour, le traitement des informations est essentiellement manuel. Les agents du 
Service Juridique consultent le journal papier afin d’identifier les publications susceptibles 
de concerner les partenaires de la RTI. Les informations jugées pertinentes sont ensuite 
retranscrites manuellement dans un document Microsoft Word servant de support de 
suivi. 
Toutefois, le Service Juridique ne dispose actuellement d’aucun outil lui 
permettant de déterminer si le partenaire mentionné dans le journal est effectivement 
référencé dans les bases de données internes de la RTI. Cette vérification n’est donc pas 
automatisée, ce qui limite la capacité à identifier rapidement les dossiers ayant un impact 
direct sur l’entreprise. 
Par ailleurs, la diffusion des informations vers les directions concernées est réalisée 
de manière manuelle, ce qui peut entraîner des délais de traitement et un risque 
d’omission. 

2-Besoins exprimés 

Afin d’améliorer ce processus, le Service Juridique souhaite disposer d’une 
application dédiée permettant de centraliser l’ensemble des informations et d’automatiser 
certaines opérations. 
L’application devra notamment permettre de : 

✓ Saisir directement les informations extraites du journal papier, sans passer par un 
document Microsoft Word ; 

✓ Enregistrer les événements juridiques relatifs aux partenaires ; 

✓ Conserver un historique des informations enregistrées ; 

✓ Effectuer des recherches multicritères sur les informations saisies. 

L’une des fonctionnalités majeures attendues consiste à interroger les bases de données 
des applications internes de la RTI afin de vérifier automatiquement si le partenaire 
concerné est référencé dans les systèmes internes. 
Enfin, après validation d’une information, l’application devra permettre de notifier 
automatiquement les directions concernées, notamment la DCMD et la DFC. 

3-Objectifs attendus 

✓ Dématérialiser le processus actuel de traitement des informations juridiques ; 

✓ Supprimer la saisie intermédiaire dans un document Microsoft Word ;

✓ Centraliser les informations dans une base de données unique et sécurisée ; 

✓ Améliorer l’identification des partenaires grâce à l’interconnexion avec les systèmes 
internes ; 

✓ Renforcer la réactivité des directions concernées grâce à un système de notification ; 

✓ Améliorer la traçabilité et la fiabilité des informations.
